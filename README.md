# Xiran Cheng · Personal Website

Xiran Cheng 的双语个人网站，记录艺术、哲学、摄影、音乐与硅光技术。

A bilingual personal archive for art, philosophy, photography, music and silicon photonics.

## 页面 / Pages

- `/` — 个人档案与内容分类 / Archive and categories
- `/about` — 个人介绍与教育经历 / Profile and education

## 本地运行 / Run locally

需要 Node.js 22.13 或更新版本。

```bash
npm install
npm run dev
```

打开 `http://localhost:3000`。

## 构建检查 / Production build

```bash
npm run build
```
